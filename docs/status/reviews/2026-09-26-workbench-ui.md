# 2026-09-26 工作台与 Document 视觉落地

实施基线：`1f76d19`。项目所有者认可 v1.1 静态稿后，授权继续共享工作台与 Document 的有限 React 落地。视觉依据为[已认可设计](../../design/workbench-v1.md)，业务合同仍为 [ADR-0028](../../adr/0028-minimal-markdown-document.md)。

## 完成范围

- `WorkbenchShell.tsx` 承载已登录页面的 224px 桌面导航、移动端品牌栏、原生模态导航抽屉、账户和退出入口；共享暖纸底、灰玉品牌色与墨蓝主操作。
- Document 阅读页集中展示标题、版本、来源 Ticket 与 Markdown；信息默认收起，展开后显示当前可见范围、来源与活动。桌面信息栏 288px；1180px 及以下使用独立单栏信息视图，返回保留阅读位置与触发按钮焦点。
- 编辑页保留 textarea 原文、显式预览、未保存提示、放弃和保存。冲突比较、历史恢复确认、提交结果未知的精确重试及撤权清空沿用既有状态机。
- 增加跳到主要内容入口；页内锚点不会误触发离开草稿确认。历史加载与进入编辑将焦点移至对应内容，文档信息支持 Escape 返回。
- 首页共享主题收敛为相同视觉语言；登录与显式静态原型保留原布局。文档列表沿用既有行为并调整列表排版。

没有新增依赖、字体、图标库、API、数据库迁移、权限或浏览器持久化。没有执行 push、PR、发布或部署。

## 设计与实际数据的映射

侧栏只展示 Session 可提供的 Workspace 和真实导航入口，Document 工具栏通过当前返回的 Project ref 导向项目文档列表，不伪造 API 尚未提供的 Project 名称或对象树。未提供活动时显示“暂无可见活动”。移动端主操作保留在可换行工具栏，不引入可能遮挡输入的固定底部栏。真实软键盘遮挡仍需真机复核。

## 验证

- `./scripts/check-web.sh`：17 个测试文件、113 项测试通过，包含文档信息焦点返回、展开时撤权清理、历史恢复必须确认、草稿页内跳转及原有保存 / 冲突 / 精确重试行为；Prettier、Oxlint、严格 TypeScript、生产构建及 152 个锁定 package 的依赖基线通过。
- 浏览器使用本地 Vite、独立 Chromium 会话与虚构 API 响应，检查正式 React DOM；截图和页面交互证据保存在忽略目录 `output/playwright/`，不包含真实成员或工作区数据。

- Chromium 阅读与编辑分别检查 1440、1024、768、390、320px 宽度，无水平溢出。已查看桌面阅读 / 信息展开、手机阅读 / 编辑 / 信息 / 冲突及首页截图。
- 浏览器实际执行预览、模拟 409、草稿保留、显式重新应用与再次保存；历史入口展示旧版与当前版比较。恢复确认的取消 / 确认由组件测试覆盖，本轮浏览器未提交恢复写入。
- 手机导航验证初始焦点、Tab / Shift+Tab 循环与 Escape 返回菜单按钮；发现原生 dialog 反向 Tab 可把焦点交给浏览器后，补充显式首尾循环并复验通过。文档信息验证焦点、Escape、返回原阅读滚动位置；模拟撤权后正文、历史、展开信息与来源均清除。
- 收尾重跑暴露原有创建重试测试的时序竞争：pending 入口早于首次请求失败出现；测试改为先等待失败反馈及按钮启用，再模拟用户重试，不放宽生产逻辑或断言。
- 临时 Vite 与隔离 Chromium 已关闭。
- `./scripts/check-repo.sh` 与 `git diff --check` 通过。首次浏览器写入尝试因 fixture 的 CSRF 长度及预览路径错误未通过，修正虚构数据后重跑；未修改生产 CSRF 或 API 校验来适配 fixture。

## 证据边界

本轮浏览器 mock 仅证明布局与客户端交互，未启动真实 Go / PostgreSQL，也不证明保存后的服务端 Markdown 投影或真实授权链；此前真实链路证据见[最小 Document 记录](2026-09-26-markdown-document.md)。中文字符串填充不等于原生输入法验证。macOS 中文 IME 人工验收继续按所有者要求暂缓；读屏、真机软键盘、深色主题和长期团队使用未验收。
