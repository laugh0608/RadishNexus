- [ ] 逐项比对备份时点的权威表、成员权限、Decision → Ticket → Document 来源与审计 / receipt 摘要，核对 Activity 13。验证旧 Session 失效，重新登录后权限符合预期，并用同一请求精确重试复核 receipt。准备开放时记录唯一可写实例及其身份。
