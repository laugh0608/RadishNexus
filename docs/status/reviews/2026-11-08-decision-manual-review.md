使用一次性 Chrome 会话和仅监听本机的隔离实例。TLS 由仓库既有 `contextHTTPS` 测试入口提供，Chrome 会话限定本次 fixture 的证书公钥。测试使用合成账户和数据，退出后清理浏览器、数据库容器及临时文件。

| 验收项 | 观察结果 |
| --- | --- |
| R01 普通成员主链 | 以具有 Project 决策权的普通成员登录，从工作区首页经 Project 决策列表进入已接受结论。分别用原讨论及补充 Thread 记录「仍适用」，再记录「需重新评估」。从原讨论发起新提案、接受并明确替代旧结论。刷新后双方仍能追溯替代，旧页保留原结论及三条复核。经原关系重开已有 Ticket 至状态版本 6，沿原 Ticket 链接保存既有 Document 至版本 4 |
| R02 撤权与页面恢复 | 从复核记录打开补充 Thread，再用正式管理命令移除成员的该 Thread 权限。Chrome 后退实际触发 `pageshow.persisted=true`。页面重读后，依赖补充 Thread 的复核说明和链接均消失，仍可读的原讨论复核保留。重新授权并刷新后恢复可读历史 |
